Premiers pas

Installer une aventure

  1. 1

    Récupérez le fichier du jeu

    Enregistrez le fichier .avelunegame dans l’app Fichiers.

  2. 2

    Ouvrez Avelune

    Touchez « Ajouter » dans votre bibliothèque.

  3. 3

    Sélectionnez l’aventure

    Avelune vérifie le fichier puis installe sa cartouche dans votre collection.

Questions fréquentes

Les réponses avant le message de détresse.

Mon jeu refuse de s’installer

Vérifiez que le téléchargement est terminé et que le fichier porte bien l’extension .avelunegame. Si l’erreur continue, joignez le message affiché à votre demande d’assistance.

Où sont mes sauvegardes ?

Elles restent sur votre appareil. Supprimer Avelune peut aussi supprimer les données locales de l’application.

Faut-il créer un compte ?

Non. Avelune fonctionne sans inscription, sans connexion et sans profil utilisateur.

Quoi joindre à mon message ?

Indiquez votre modèle d’iPhone ou d’iPad, votre version d’iOS, la version d’Avelune et, si possible, une capture du problème.
